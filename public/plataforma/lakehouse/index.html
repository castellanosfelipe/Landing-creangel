LakeHouse

Integra almacenamiento de datos, consultas SQL, procesamiento analítico y acceso a conjuntos de datos de distintos formatos.

Capacidades principales

Una primera mirada a lo que puede hacer con este producto.

  1. 01

    Consulta de datos

    Permite consultar datos mediante SQL.

  2. 02

    Viaje en el tiempo

    permite realizar consultas reproducibles que utilizan exactamente la misma instantánea de tabla o permite a los usuarios examinar fácilmente los cambios.

  3. 03

    Formato de almacenamiento

    Utiliza almacenamiento en columnas para optimizar las operaciones de escaneo y agregación, mejorando el rendimiento de las consultas.

  4. 04

    Volcado de datos

    Capacidad para volcar consultas a diferentes formatos de archivo, CSV, JSON, XML.

  5. 05

    Carga de información

    Permite cargar conjuntos de datos por una interfaz web para su procesamiento en la bodega o el lago de datos.

  6. 06

    integración

    El sistema puede integrarse vía REST API con sistemas de analítica como Tableau y Power BI.
