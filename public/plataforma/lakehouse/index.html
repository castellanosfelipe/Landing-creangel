Características técnicas 5 características

Tipos de datos extendidos

Características técnicas

tienen acceso a una gama más amplia de datos que los data WareHouse, lo que les permite acceder a registros del sistema, audio, video y archivos.

Transmisión de datos

Características técnicas

permiten realizar informes en tiempo real al admitir análisis en linea, especialmente cuando se utilizan con productos de integración.

Esquemas

Características técnicas

los data LakeHouse aplican esquemas a los datos, lo que ayuda a la estandarización de grandes volúmenes de datos.

Compatibilidad con BI y análisis

Características técnicas

Arquitectura Open

Data Lake 9 características

Formato de Datos Semi-estructurados

Data Lake

formato de tabla abierto para conjuntos de datos analíticos de gran tamaño.

Consulta de datos

Data Lake

Permite consultar datos mediante SQL.

Partición oculta

Data Lake

Administra las particiones de datos sin requerir que el usuario las especifique en cada consulta.

Evolución de las Particiones

Data Lake

puede actualizar el diseño de una tabla a medida que cambian el volumen de datos o los patrones de consulta.

Viaje en el tiempo

Data Lake

permite realizar consultas reproducibles que utilizan exactamente la misma instantánea de tabla o permite a los usuarios examinar fácilmente los cambios.

reversión de la versión

Data Lake

permite a los usuarios corregir rápidamente los problemas restableciendo las tablas a un estado correcto.

Filtrado Avanzado

Data Lake

Los archivos de datos se reducen con estadísticas de nivel de columna y partición, utilizando metadatos de tabla.

Manejo de Versiones

Data Lake

El control de versiones a nivel de objeto es una evolución significativa en comparación con los enfoques de control de versiones de SAN y NAS.

Gobernanza y cumplimiento

Data Lake

Mantiene metadatos y políticas de retención para apoyar la gobernanza de datos.

Data WareHouse (Columnar Database) 5 características

Formato de almacenamiento

Data WareHouse (Columnar Database)

Utiliza almacenamiento en columnas para optimizar las operaciones de escaneo y agregación, mejorando el rendimiento de las consultas.

Indexación

Data WareHouse (Columnar Database)

Emplea técnicas de indexación avanzadas, incluidos índices de mapa de bits e invertidos, para acelerar el procesamiento de consultas al permitir el filtrado y la recuperación…

lenguaje de consulta

Data WareHouse (Columnar Database)

un dialecto de SQL diseñado para consultas analíticas, que permite a los usuarios realizar agregaciones y filtrados complejos con una sintaxis familiar.

Escalabilidad

Data WareHouse (Columnar Database)

Presenta una arquitectura distribuida con nodos especializados (por ejemplo, Broker, Histórico, Tiempo real, Coordinador) que se pueden escalar independientemente para manejar…

Seguridad

Data WareHouse (Columnar Database)

Incluye autenticación, control de acceso basado en roles e integración con LDAP.
