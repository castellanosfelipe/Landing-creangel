ICBF

CHALLENGE

Achieve excellence in the services provided on the web portal www.icbf.gov.co, implementing a Search Solution within the portal that allows them to find information simultaneously from the various repositories of the entity, adapt to the way users consult, allowing the use of familiar terms, contemplate the most frequent spelling and fingering errors, as well as provide search suggestions to users.

The Solution must have the capacity to find information in digitized images, promote citizen participation by using electronic media, optimize and automate procedures and services, facilitate users of the ICBF web portal both internal and external, the search and consultation of information.

For external users the Application should facilitate access to information through the entity's web portal and should allow for user-friendly viewing of content and resources.

SOLUTION

Implement a Search-Based Application for the www.icbf.gov.co/ portal, within this application tools were developed to allow internal users of the entity access to search and query information stored in different information systems of the entity, improving performance with a real response time, finding information in digitized images, immaterializing paper documents, standardizing the website and enabling a search mechanism for content.

One of the key parts of this portal is the Creangel Search-Based Application that uses Google Search Appliance as part of its platform.
