Key capabilities

A first look at what you can do with this product.

  1. 01

    Document Load

    Collect communications in different formats to start your review.

  2. 02

    Standardisation with OCR

    Make scanned documents legible and take advantage of their content.

  3. 03

    Extraction of information

    Review each communication with key data extracted from its content.

    Classification of communications

INTELIGENT DOCUMENT PROCESSING 16 features

Analysis by Apache Tika

INTELIGENT DOCUMENT PROCESSING

After OCR, the text is sent to a specialized service (Apache Tika) that extracts textual content more precisely from the processed PDF.

Detailed Classification of Crafts

INTELIGENT DOCUMENT PROCESSING

It classifies trades into categories such as requirements of control entities, reports and circulars.

Detailed Classification of Procedures

INTELIGENT DOCUMENT PROCESSING

It classifies procedures in legal categories, including exceptions, prescriptions, embargoes and payment facilities.

Classification using AI decision flows

INTELIGENT DOCUMENT PROCESSING

Apply AI decision flows to identify the type of document and execute the corresponding sorter.

Automatic OCR Need Detection

INTELIGENT DOCUMENT PROCESSING

The system automatically identifies which documents require text recognition (scanned) and which already have digital text, applying the process only where necessary.

Extraction of facts and foundations

INTELIGENT DOCUMENT PROCESSING

The AI analyzes the body of the document to summarize the arguments, reasons or facts that justify its existence or the contained request.

Extraction of the specific application

INTELIGENT DOCUMENT PROCESSING

Extracts the request or claim of the sender from the document.

Extraction of key legal terms

INTELIGENT DOCUMENT PROCESSING

The AI identifies and extracts the most relevant legal and administrative terms from the document, facilitating subsequent search and reference.

Extraction of the unique document identifier

INTELIGENT DOCUMENT PROCESSING

The system automatically detects and extracts the file/reference number or code of the document, if present.

Structured Metadata Extraction with AI

INTELIGENT DOCUMENT PROCESSING

Extract sender, recipient, subject matter, objective, summary, legal terms and date of receipt via AI.

Automatic document type identification

INTELIGENT DOCUMENT PROCESSING

Artificial intelligence determines whether a document is an Office (formal communication) or a Procedure (application requiring administrative resolution), classifying it before the...

Search engine indexation

INTELIGENT DOCUMENT PROCESSING

The content of each document, together with its extracted metadata, is indexed in Apache Soler to allow fast and efficient searches.

Interchangeable OCR motor

INTELIGENT DOCUMENT PROCESSING

The text recognition technology can be changed between different engines (OcrMyPDF, Tesseract) according to the needs of the organization, without modifying the rest of the system.

Standardisation of content (OCR)

INTELIGENT DOCUMENT PROCESSING

For scanned documents or images, the system automatically converts visual content into computer-readable text, allowing for further analysis.

Pipeline processing in three stages

INTELIGENT DOCUMENT PROCESSING

Each document follows a mandatory sequence: (1) Content standardization → (2) Metadata extraction → (3) Classification.

Spanish and English text recognition

INTELIGENT DOCUMENT PROCESSING

The optical character recognition engine processes documents in Spanish and English simultaneously, ideal for organizations with bilingual documentation.
