Características de IFINDIT CHATGEN

Explore las funciones por categoría o encuentre una capacidad específica.

103 características

Chat con Inteligencia Artificial (Tiempo Real)10 características

Conversación por Transmisión en Tiempo Real (SSE)

El usuario recibe las respuestas de la inteligencia artificial letra a letra, de forma progresiva y fluida, sin necesidad de esperar a que la respuesta completa esté lista para verla en pantalla.

Indicador de Progreso de Generación

Mientras la IA elabora su respuesta, el sistema muestra mensajes de progreso que informan al usuario en qué etapa se encuentra el proceso.

Guardado Automático del Historial de Conversación

Cada mensaje del usuario y cada respuesta de la IA se guardan automáticamente en el historial de la conversación para mantener el contexto.

Modo de Chat sin Transmisión (No Streaming)

En casos donde la transmisión en tiempo real no sea adecuada, el sistema puede entregar la respuesta completa de una sola vez.

Sugerencias de Preguntas en Tiempo Real

El sistema puede generar automáticamente sugerencias de preguntas relacionadas con el tema de la conversación, ayudando al usuario a continuar el diálogo.

Caja de Búsqueda Inteligente (OneBox)

Modalidad especial de consulta que combina búsqueda semántica y respuesta generativa para ofrecer resultados directos a preguntas específicas.

Sugerencias en el OneBox

La caja de búsqueda inteligente también puede generar sugerencias de consultas relacionadas en tiempo real.

Validación de Conversación Activa

El sistema verifica que la conversación exista y esté activa antes de procesar cualquier mensaje, evitando errores por conversaciones inválidas o cerradas.

Validación de Compatibilidad Widget-Configuración

El sistema verifica automáticamente que el tipo de widget y la configuración de IA sean compatibles antes de iniciar cualquier conversación.

Validación de Origen de las Solicitudes

El sistema verifica que las solicitudes provengan de orígenes autorizados, bloqueando accesos desde sitios no permitidos.

Agentes de Inteligencia Artificial8 características

Agente Simple

Tipo básico de agente que procesa la consulta del usuario y genera una respuesta directa utilizando el modelo de lenguaje configurado.

Agente ReAct (Razonamiento y Acción)

Combina el procesamiento de consultas con el uso de herramientas mediante un agente ReAct.

Agente de Planificación

Agente que primero elabora un plan de pasos para resolver la consulta y luego los ejecuta en orden, ideal para tareas complejas de múltiples etapas.

Agente de Razonamiento

Incluye un tipo de agente orientado a consultas que requieren razonamiento previo a la respuesta.

Ejecución Asíncrona de Tareas de Agente

Las tareas complejas de los agentes se procesan en segundo plano sin bloquear la interfaz del usuario, que recibe una notificación cuando terminan.

Envío de Tareas a Cola de Procesamiento (Kafka)

Envía las tareas de los agentes a una cola Kafka para su procesamiento asíncrono.

Tarea de Agente: Creación y Seguimiento

Cada tarea asignada a un agente se registra con un identificador único que permite hacer seguimiento de su estado (pendiente, en proceso, completada).

Agente Configurado por Widget

El tipo y comportamiento del agente se determina automáticamente según la configuración del widget de chat, sin requerir ajustes manuales por sesión.

Herramientas de los Agentes (Tools)6 características

Herramienta de Base de Conocimiento

Los agentes pueden consultar automáticamente la base de conocimiento para encontrar información relevante que respalde sus respuestas.

Herramienta de Evaluación Matemática

Permite que los agentes utilicen una herramienta de cálculo matemático.

Herramienta MCP (Protocolo de Contexto de Modelos)

Los agentes pueden conectarse a servidores MCP externos para acceder a funcionalidades y datos adicionales de forma estandarizada.

Registro de Llamadas a Herramientas

Cada vez que un agente utiliza una herramienta, la llamada queda registrada con sus parámetros y resultado para auditoría y trazabilidad.

Marco de Herramientas Extensible

El sistema está diseñado para agregar nuevas herramientas sin modificar el código principal de los agentes, usando una interfaz base común.

Gestión de Herramientas desde el Panel de Administración

El administrador puede crear, editar y eliminar herramientas disponibles para los agentes desde la interfaz de gestión.

Integración con Protocolo MCP3 características

Cliente MCP

El sistema puede conectarse como cliente a servidores MCP externos para solicitar capacidades adicionales de forma estandarizada.

Puente HTTP-STDIO para MCP

El sistema puede comunicarse con servidores MCP que operan a través de entrada/salida estándar, usando un puente HTTP como intermediario.

Gestión de Servidores MCP

El administrador puede registrar, editar y eliminar los servidores MCP que los agentes pueden utilizar.

Recuperación Aumentada por Generación (RAG)5 características

Búsqueda Semántica sobre Base de Conocimiento

El sistema busca documentos relevantes no por palabras exactas, sino por el significado de la consulta, encontrando información relacionada aunque no use las mismas palabras.

Reordenador de Resultados (Reranker)

Después de la búsqueda semántica, el sistema aplica un segundo filtro de relevancia que reordena los documentos encontrados para priorizar los más útiles para la respuesta.

Generación de Respuesta Basada en Documentos (RAG)

Genera respuestas a partir de los documentos recuperados de una base de conocimiento mediante RAG.

Configuración RAG por Widget

Cada widget de chat puede tener su propia configuración de RAG, apuntando a diferentes bases de conocimiento según el caso de uso.

Gestión de Configuraciones RAG

El administrador puede crear, editar y eliminar configuraciones de RAG desde el panel de gestión.

Base de Conocimiento y Almacenamiento Vectorial5 características

Creación de Base de Conocimiento

El administrador puede crear repositorios de documentos que los agentes e IA utilizarán como fuente de información para responder.

Gestión de Colecciones Vectoriales

Los documentos de la base de conocimiento se organizan en colecciones especiales que permiten búsquedas por significado de forma eficiente.

Proveedor de Almacenamiento Vectorial: ChromaDB

El sistema usa ChromaDB como motor de almacenamiento de vectores, que permite buscar documentos por similitud semántica.

Almacenamiento de Archivos en MinIO

Almacena archivos de la base de conocimiento en MinIO, compatible con almacenamiento de objetos S3.

Gestión de Almacenes Vectoriales

El administrador puede crear, configurar y eliminar los almacenes de vectores disponibles para las bases de conocimiento.

Modelos de Lenguaje (LLM)6 características

Gestión de Modelos de Lenguaje

El administrador puede registrar y configurar diferentes modelos de lenguaje (LLM) que los chatbots pueden utilizar.

Selección de LLM por Configuración de Chat

Cada chatbot puede configurarse para usar un modelo de lenguaje específico, permitiendo optimizar costos y capacidades.

Monitoreo de Uso de Tokens

El sistema registra cuántos tokens (unidades de texto) consume cada conversación, permitiendo controlar los costos de uso de los LLM.

Caché de Respuestas del LLM

El sistema puede almacenar temporalmente respuestas frecuentes del modelo de lenguaje para entregarlas más rápido sin volver a generarlas.

Configuración de Caché por LLM

El administrador puede configurar si y cómo se almacenan en caché las respuestas de cada modelo de lenguaje.

Caché de Respuestas con Redis

Utiliza Redis para almacenar y recuperar respuestas en caché.

Sistema de Prompts y Plantillas de Respuesta5 características

Gestión de Prompts del Sistema

El administrador puede crear y editar las instrucciones base que guían el comportamiento de la IA en cada chatbot.

Gestión de Configuraciones de Prompting

Permite configurar cómo se construyen y combinan los prompts del sistema con los mensajes del usuario.

Plantillas de Respuesta

El administrador puede definir formatos de respuesta predefinidos que la IA puede usar para estructurar sus respuestas de manera consistente.

Sanitización del Historial del Asistente

El sistema limpia automáticamente el historial de la IA antes de enviarlo como contexto, eliminando etiquetas técnicas o ruido que podría confundir al modelo.

Mejora Automática de Consultas (Enhancement)

El sistema puede mejorar automáticamente la consulta del usuario antes de procesarla, haciéndola más clara y completa para el modelo.

Configuración de Chat y Widgets10 características

Creación de Configuraciones de Chat

El administrador puede crear configuraciones que definen el comportamiento completo de un chatbot: tipo de IA, modelo, prompts, herramientas y más.

Tipos de Aplicación IA: RAG y Agente

El sistema soporta dos modos principales de chatbot: RAG (responde basándose en documentos) y Agente (usa herramientas y razonamiento para resolver tareas).

Creación y Gestión de Widgets

Permite crear y gestionar widgets de chat para insertarlos en sitios web y aplicaciones.

Widget de Tipo Chat

Widget interactivo de conversación que permite a los usuarios chatear con la IA de forma natural.

Prueba de Widget desde el Panel

El administrador puede probar el funcionamiento de un widget directamente desde el panel de gestión antes de publicarlo.

Control de Orígenes Permitidos por Widget

El administrador puede definir desde qué sitios web puede usarse cada widget, bloqueando accesos no autorizados.

Compatibilidad Widget-Configuración

El sistema tiene reglas de compatibilidad que determinan qué configuraciones de IA son válidas para cada tipo de widget.

Inicialización de Reglas de Compatibilidad

Al iniciar, el sistema carga automáticamente las reglas de compatibilidad predeterminadas si aún no existen.

Mensaje Inicial del Widget (Welcome Message)

Cada widget puede configurarse con un mensaje de bienvenida que se muestra al usuario al iniciar la conversación.

Gestión de Interfaces de Entrada

El administrador puede configurar qué tipos de entrada acepta el widget: texto, voz, archivos, etc.

Gestión de Conversaciones6 características

Creación de Conversaciones

Los usuarios pueden iniciar nuevas conversaciones con el chatbot desde el widget o la interfaz de gestión.

Historial de Conversaciones

El sistema guarda el historial completo de cada conversación, permitiendo retomar el hilo del diálogo en sesiones futuras.

Gestión del Contexto de Conversación

El sistema mantiene y administra el contexto de la conversación para que la IA recuerde lo que se ha dicho anteriormente.

Detección Automática del Idioma

El sistema puede detectar automáticamente el idioma en que escribe el usuario y adaptar la respuesta al mismo idioma.

Usuarios Anónimos en Conversaciones

Admite conversaciones sin inicio de sesión y gestiona identificadores temporales para esos usuarios.

Contexto de Conversación Configurable

El administrador puede configurar cuántos mensajes previos se incluyen como contexto para cada nueva respuesta de la IA.

Filtrado de Contenido3 características

Filtro de Contenido Inapropiado (Profanity)

El sistema puede detectar y filtrar automáticamente mensajes con lenguaje inapropiado o contenido ofensivo antes de procesarlos.

Gestión de Listas de Filtrado

El administrador puede configurar las palabras y patrones que activarán el filtro de contenido.

Respuesta Personalizada ante Contenido Filtrado

Cuando un mensaje es filtrado, el sistema puede responder con un mensaje personalizado en lugar de ignorar la solicitud.

Infraestructura de Datos Relacionales (RDB)4 características

Gestión de Bases de Datos Relacionales

El administrador puede registrar bases de datos relacionales (como PostgreSQL) que los agentes pueden consultar para obtener información estructurada.

Gestión de Tablas de Base de Datos

Permite configurar qué tablas de la base de datos son accesibles para los agentes.

Gestión de Columnas de Tablas

Permite definir qué columnas de cada tabla son visibles y consultables por los agentes.

Consulta de Datos Relacionales por Agentes

Los agentes pueden consultar bases de datos relacionales para obtener información estructurada que respalde sus respuestas.

Transcripción y Traducción2 características

Transcripción de Audio a Texto

El sistema puede convertir mensajes de voz o audio en texto para procesarlos como consultas al chatbot.

Traducción Automática de Mensajes

El sistema puede traducir automáticamente los mensajes del usuario o las respuestas de la IA a diferentes idiomas.

Integración con WhatsApp4 características

Productor de Mensajes para WhatsApp

El sistema cuenta con un servicio dedicado que recibe mensajes de WhatsApp y los envía a la cola de procesamiento del chatbot.

Webhook de WhatsApp

El sistema expone un punto de conexión (webhook) que WhatsApp usa para enviar los mensajes de los usuarios.

Procesamiento de Mensajes Entrantes de WhatsApp

Los mensajes recibidos por WhatsApp son procesados y respondidos por la inteligencia artificial de forma automática.

Respuesta Automática vía WhatsApp

Tras procesar el mensaje del usuario, el sistema envía la respuesta de vuelta al usuario a través de WhatsApp.

Claves de API y Seguridad5 características

Gestión de Claves de API

El administrador puede crear y gestionar claves de acceso que permiten a aplicaciones externas conectarse al servicio de chat.

Autenticación Multiinquilino (Multi-Tenant)

Admite varias organizaciones con separación de datos y configuración por inquilino.

Gestión de Inquilinos (Tenants)

El administrador puede crear y gestionar las organizaciones que usan la plataforma de chat.

Cifrado de Datos Sensibles

Las credenciales y datos sensibles almacenados en la base de datos se cifran automáticamente para protegerlos.

Rutas Públicas sin Autenticación

El sistema distingue entre rutas que requieren autenticación y rutas públicas accesibles sin credenciales, como el endpoint del widget de chat.

Procesamiento Asíncrono y Cola de Tareas6 características

Cola de Tareas con Apache Kafka

Envía tareas de procesamiento intensivo a Apache Kafka para ejecutarlas en segundo plano.

Consumidor de Tareas Asíncronas

Un servicio independiente lee continuamente las tareas de la cola y las ejecuta en segundo plano.

Cola de Mensajes Fallidos (DLQ)

Dirige las tareas que fallan a una cola de mensajes fallidos para su revisión.

Consumidor de Eventos de Base de Datos

Un servicio dedicado procesa los eventos de cambio en la base de datos para mantener sincronizados los diferentes componentes del sistema.

Procesador de Eventos de Base de Datos

Transforma y aplica los eventos recibidos de la base de datos, ejecutando las operaciones necesarias en respuesta a cambios.

Recarga Dinámica del Consumidor

El servicio consumidor puede recargarse en caliente sin necesidad de reiniciar todo el sistema cuando cambia la configuración.

Programador de Tareas (Scheduler)3 características

Servicio de Programación de Tareas

El sistema incluye un planificador que ejecuta tareas automáticas en horarios predefinidos, sin intervención manual.

Trabajos Periódicos Configurables

El administrador puede definir qué tareas se ejecutan automáticamente y con qué frecuencia.

Ejecución Autónoma en Segundo Plano

El planificador opera de forma independiente al servidor principal.

Panel de Administración (Frontend TypeScript)8 características

Módulo de Configuración de Chat

Interfaz para crear, editar y administrar las configuraciones de los chatbots, incluyendo modelo, prompts y herramientas.

Módulo de Gestión de Widgets

Interfaz para crear, configurar, probar y publicar los widgets de chat que se insertan en sitios web.

Módulo de Base de Conocimiento

Interfaz para gestionar las bases de documentos que alimentan las respuestas del chatbot.

Módulo de Infraestructura de Datos

Interfaz para registrar y gestionar las bases de datos relacionales y almacenes de vectores conectados al sistema.

Módulo de Conversaciones

Interfaz para visualizar y gestionar el historial de conversaciones de todos los usuarios.

Módulo de Auditoría

Interfaz para revisar registros de actividad, errores y uso del sistema.

Módulo de LLM (Modelos de Lenguaje)

Interfaz para registrar y configurar los modelos de lenguaje disponibles para los chatbots.

Página de Prueba de Widget

Página dedicada en el panel donde el administrador puede probar el widget de chat en tiempo real antes de publicarlo.

Arquitectura y Operaciones4 características

Arquitectura Multi-Dominio

El backend está organizado en dominios funcionales independientes: motor LLM, gestor de chat, widgets e identidad, facilitando el desarrollo y mantenimiento independiente de cada área.

API Multi-Inquilino

La API admite varias organizaciones y separa sus datos y configuraciones por inquilino.

Servidor de Producción con Gunicorn

En producción, el sistema usa Gunicorn como servidor web de alta capacidad, con configuración personalizable de trabajadores.

Despliegue con Docker y Docker Compose

Permite desplegar los servicios mediante Docker y Docker Compose.
