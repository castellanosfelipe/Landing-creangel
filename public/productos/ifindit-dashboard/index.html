Integración con interfaz de codigo en python

Compatibilidad con Múltiples Lenguajes de Programación

Creación y edición2 características

Biblioteca de visualizaciones

Ofrece una biblioteca de gráficos, mapas y visualizaciones para construir paneles personalizados.

Proyecto

Un proyecto es una categoría personalizada que agrupa uno o más tableros de control, permitiendo organizar y centralizar la información según sus necesidades específicas.

Sistema de Filtros7 características

Filtros individuales del dashboard

Filtra campos por categorías, rangos de fechas, rangos numéricos y coincidencia de texto.

Filtros personalizados en paneles

Cada panel puede tener sus propios filtros independientes, configurables desde el espacio de trabajo de paneles.

Grupos de filtros y condiciones

Permite construir lógica de filtrado compleja mediante grupos jerárquicos con operadores lógicos (AND/OR).

Filtros interactivos en el viewer

En el modo de visualización, el usuario puede activar un panel flotante de filtros para modificar los valores activos sin entrar al modo de edición.

Filtros jerárquicos (componente visual)

Tipo especial de componente visual dentro de los paneles que permite filtrar datos de forma interactiva mediante una selección en árbol o jerarquía.

Filtros de selección (componente visual)

Tipo de componente visual que presenta una lista desplegable o de selección múltiple para filtrar los datos del dashboard.

Calendario dinamico

Permite seleccionar rangos de fechas para filtrar los tableros y analizar períodos específicos.

Tableros de control13 características

Descripción General

El Tablero de Control Interactivo es una herramienta diseñada para centralizar y organizar visualizaciones clave mediante la integración de uno o más paneles (gráficas).

Creación y edición de Tablero de control

El usuario puede crear nuevos Tablero de control especificando nombre, descripción y configuración inicial.

Visualización de Tablero de control (modo viewer)

Presenta el dashboard en modo solo lectura para el consumo de información.

Editor visual de Tablero de control

Entorno de trabajo donde el usuario puede componer el tablero agregando, moviendo, redimensionando y eliminando paneles.

Layout responsivo

Cada dashboard gestiona la disposición de sus paneles de acuerdo al tamaño de pantalla con el que se quiera visualizar.

Configuración del dashboard

Define el comportamiento global del tablero: búsqueda por texto, exportación a PDF, color de fondo y espaciado de la grilla.

Gestión de fuentes de datos del dashboard

Permite asociar varias fuentes de datos a un tablero y administrar sus conexiones.

Información adicional del dashboard

Permite registrar metadatos complementarios como URL de referencia, título alternativo y descripción extendida, útiles para documentar el propósito de cada grafica.

Publicación y control de visibilidad

Controla si un dashboard es público o privado, y si ha sido publicado para consumo general.

Pestañas y navegación lateral del dashboard

El workspace del dashboard incluye un menú lateral con pestañas que permiten navegar entre la biblioteca de paneles, la configuración y los filtros del dashboard, sin salir de la vista de edición.

Herramientas de Personalización Avanzada

Permite modificar el diseño y la disposición de los paneles del tablero.

Adaptabilidad a Requerimientos Específicos

Configurar tableros para cumplir con metas específicas, alineándolos con las necesidades de cada área o proyecto.

Descarga de datos del tablero

Permite descargar los datos de un tablero de control en PDF, CSV y Excel.

Paneles18 características

Descripción General

Genera paneles gráficos a partir de vistas materializadas integradas en la plataforma.

Creación y edición de paneles

El usuario puede crear un nuevo panel definiendo su título, descripción y tipo de gráfica.

Espacio de trabajo de paneles (Panel Workspace)

Entorno visual dedicado al diseño y configuración completa de un panel.

Selección de tipo de gráfica

Desde el espacio de trabajo, el usuario elige el tipo de visualización deseado de una biblioteca de gráficas.

Configuración de la consulta de datos

Define cómo se recuperan los datos para el panel: fuente de datos, campos seleccionados, límite de registros, reglas de ordenamiento y grupos de filtros aplicados.

Previsualización del gráfico

Muestra en tiempo real el resultado visual de la configuración del panel antes de guardar.

Biblioteca de paneles

Vista centralizada de todos los paneles disponibles dentro de un proyecto, organizados por carpetas.

Eliminación de paneles

Permite eliminar un panel de forma permanente o desvincularlo de un dashboard específico.

Descarga del gráfico

El usuario puede exportar la visualización del panel como archivo.

Visibilidad y publicación de paneles

Controla si un panel es público o privado, y si ha sido publicado para consumo general.

Creación y Edición Intuitiva

Diseñe y ajuste paneles gráficos de manera sencilla.

Visualización Detallada y Clara

Cada panel ofrece una representación visual comprensible, ideal para convertir datos en información accionable, incluso para usuarios con experiencia técnica limitada.

Herramientas de Personalización Avanzadas

Adapte colores, formatos y estructuras de los gráficos para reflejar los objetivos del análisis.

Optimización para Análisis Estratégico

Los gráficos están diseñados para proporcionar una perspectiva útil y precisa, convirtiéndose en una herramienta indispensable para el análisis estratégico de los datos.

Cambiar tipo de grafica

Permite cambiar el tipo de gráfico y ajustar su presentación.

Enlaces e integración de gráficas

Genera un enlace para abrir cada gráfica de forma individual o integrarla en otros sistemas.

Interpretación de gráficas con IA

Genera interpretaciones en lenguaje natural para las gráficas seleccionadas mediante inteligencia artificial generativa.

Maximizar visualización de la grafica

Permite ampliar una gráfica para consultar sus detalles.

Sistema de Paletas de Color4 características

Gestión de paletas de color

Permite crear, editar, listar y eliminar paletas de color personalizadas.

Colores de paleta

Cada paleta contiene un conjunto de colores individuales definidos en formato hexadecimal.

Estrategias de color

Define la forma en que los colores de una paleta se asignan a los elementos de una gráfica (por categoría, por gradiente, por valor, etc.).

Configuración de color personalizado

Desde el espacio de trabajo de paneles, el usuario puede definir colores específicos para elementos individuales de una gráfica, complementando o sobreponiendo la paleta general.

Sistema de Componentes de Panel5 características

Componentes de panel

Elementos de interfaz reutilizables que se agregan a un panel para controlar aspectos específicos de su visualización (encabezados, configuraciones de color, opciones de publicación, etc.).

Contenido de componentes de panel

Configura componentes con valores de texto, URL, enteros, colores, booleanos, listas y sombras mediante controles visuales.

Componentes de parámetros de gráfica

Elementos específicos de cada tipo de gráfica que permiten ajustar su apariencia y comportamiento visual con mayor detalle (ejes, leyendas, etiquetas, márgenes, animaciones, etc.).

Contenido de parámetros de gráfica

Almacena los valores de cada parámetro de configuración de la gráfica.

Plantillas de parámetros de gráfica

Define los parámetros configurables para cada tipo de gráfica.

Biblioteca de Gráficas8 características

Familias de gráficas

Agrupa los tipos de gráficas en categorías lógicas para facilitar su exploración y selección.

Gestión de campos

Define dimensiones y medidas con alias y operaciones de conteo, suma, promedio, mínimo y máximo.

Gráficas de Barras

Incluye barras horizontales y verticales, simples, agrupadas, apiladas y con varios campos.

Gráficas de Área y Líneas

Incluye áreas, líneas de una serie, series temporales y líneas apiladas.

Gráficas Circulares

Incluye gráficos circulares, de anillo y solares.

Mapas

Incluye mapas de Colombia y Bogotá, departamentos, municipios, localidades, subredes, UPZ y filtros por polígonos.

Tablas

Incluye tablas simples, multicolumna, ramificadas, anidadas y con formato condicional.

Otras Visualizaciones Avanzadas

Incluye Marimekko, indicadores, embudos, medidores, cascadas, calendarios, mapas de calor, pirámides, radar, Sankey, waffle y gráficos financieros, entre otras visualizaciones.

Catálogo de Datos (Integración)3 características

Consulta de fuentes de datos del catálogo

Permite obtener la información de las fuentes de datos disponibles registradas en el catálogo externo.

Consulta de campos del catálogo

Recupera los campos disponibles de una fuente de datos del catálogo para que el usuario pueda seleccionarlos al construir la consulta de un panel.

Información de fuentes de datos en dashboard

Muestra al usuario, dentro del contexto del dashboard o el panel, información detallada sobre las fuentes de datos asociadas, incluyendo tooltips y metadatos relevantes para facilitar la interpretación de los datos visualizados.

Pantalla de Inicio y Navegación4 características

Pantalla de inicio

Muestra al usuario los dashboards y paneles marcados como favoritos y los recursos modificados recientemente, ofreciendo acceso directo a los activos analíticos de mayor interés sin navegar por la jerarquía completa.

Barra de navegación principal

Componente lateral persistente que permite desplazarse entre los módulos principales: inicio, proyectos, favoritos, catálogo de productos, logs y configuración.

Navegación por migas de pan (Breadcrumbs)

Indica al usuario su ubicación actual dentro de la jerarquía de navegación (organización > proyecto > carpeta > recurso) y permite retroceder a cualquier nivel con un clic.

Explorador de recursos

Vista de árbol o navegador lateral que permite explorar la estructura jerárquica de proyectos, carpetas y recursos de forma intuitiva, con soporte para expansión y colapso de nodos.
