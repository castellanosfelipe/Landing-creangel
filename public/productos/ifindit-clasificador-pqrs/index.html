IFINDIT CLASIFICADOR DE PQRS

Normaliza documentos, extrae metadatos y clasifica comunicaciones y trámites mediante inteligencia artificial, con seguimiento del procesamiento y búsqueda.

Prepare los documentos

Normalice archivos y extraiga su contenido para el procesamiento.

Clasificación con IA

Clasifique oficios y trámites y extraiga metadatos de las comunicaciones.

Siga cada procesamiento

Consulte documentos y estados, busque resultados y revise la información extraída.

GESTIÓN DE DOCUMENTOS19 características

Actualización automática de la lista

Actualiza periódicamente la lista de documentos para mostrar el estado del procesamiento.

Almacenamiento alternativo en sistema de archivos

Para entornos sin servidor de almacenamiento en nube, los documentos pueden guardarse directamente en el sistema de archivos del servidor.

Almacenamiento seguro en nube privada

Todos los documentos cargados se guardan en un servidor de almacenamiento privado (MinIO), equivalente a un disco duro empresarial en la red interna.

Arrastrar y soltar archivos

El usuario puede tomar documentos desde su escritorio o carpetas y soltarlos directamente en la pantalla para subirlos, sin necesidad de buscar manualmente.

Carga masiva de archivos

Permite seleccionar y cargar varios documentos en una misma operación.

Confirmación explícita de carga

El sistema no sube los archivos automáticamente; requiere que el usuario presione un botón de confirmación para iniciar la transferencia.

Descarga de documentos originales

Permite descargar al computador del usuario el archivo original que fue cargado al sistema.

Diálogo de confirmación antes de eliminar

Antes de borrar documentos se muestra un mensaje de advertencia indicando los nombres de los archivos que serán eliminados, solicitando confirmación del usuario.

Eliminación individual de documentos

Botón de borrado en cada fila para eliminar un documento específico, con confirmación previa para evitar errores.

Eliminación masiva de documentos

Cuando hay varios documentos seleccionados, aparece un botón que los elimina todos simultáneamente, con diálogo de confirmación.

Indicador de actualización en tiempo real

Mientras la lista se refresca automáticamente, un ícono animado le indica al usuario que los datos están siendo actualizados.

Listado paginado de documentos

Muestra los documentos de la organización en una tabla paginada con cantidad de registros configurable.

Límite de tamaño por archivo

Admite archivos de hasta 50 MB.

Ordenamiento por columnas

El usuario puede ordenar la lista de documentos por nombre o por fecha de carga, haciendo clic en el encabezado de cada columna.

Renombrado automático ante duplicados

Si ya existe un documento con el mismo nombre en la organización, el sistema genera automáticamente un nombre alternativo agregando un número o sufijo, evitando sobrescrituras accidentales.

Selección de archivos desde explorador

Botón de selección que abre el explorador de archivos del sistema para escoger uno o varios documentos a cargar.

Selección múltiple de documentos

Casillas de verificación en cada fila permiten seleccionar varios documentos a la vez para aplicarles acciones en lote.

Soporte de múltiples formatos de archivo

El sistema acepta documentos en formato PDF, imágenes (JPG, JPEG, PNG, GIF) y documentos de texto (DOC, DOCX).

Vista previa de archivos antes de confirmar

Antes de enviar los documentos al sistema, se muestra una lista de los archivos elegidos con su nombre, tamaño y tipo, permitiendo revisar y eliminar los no deseados.

PROCESAMIENTO INTELIGENTE DE DOCUMENTOS16 características

Análisis por Apache Tika

Después del OCR, el texto se envía a un servicio especializado (Apache Tika) que extrae el contenido textual de manera más precisa desde el PDF procesado.

Clasificación detallada de Oficios

Clasifica oficios en categorías como requerimientos de entes de control, informes y circulares.

Clasificación detallada de Trámites

Clasifica trámites en categorías legales, entre ellas excepciones, prescripción, embargos y facilidades de pago.

Clasificación mediante flujos de decisión con IA

Aplica flujos de decisión con IA para identificar el tipo de documento y ejecutar el clasificador correspondiente.

Detección automática de necesidad de OCR

El sistema identifica automáticamente qué documentos requieren reconocimiento de texto (escaneados) y cuáles ya tienen texto digital, aplicando el proceso solo donde es necesario.

Extracción de hechos y fundamentos

La IA analiza el cuerpo del documento para resumir los argumentos, razones o hechos que justifican su existencia o la solicitud contenida.

Extracción de la solicitud específica

Extrae la petición o pretensión del remitente a partir del documento.

Extracción de términos legales clave

La IA identifica y extrae los términos jurídicos y administrativos más relevantes del documento, facilitando la búsqueda y referencia posterior.

Extracción del identificador único del documento

El sistema detecta y extrae automáticamente el número o código de radicado/referencia del documento, si está presente.

Extracción estructurada de metadatos con IA

Extrae remitente, destinatario, asunto, objetivo, resumen, términos legales y fecha de recepción mediante IA.

Identificación automática del tipo de documento

La inteligencia artificial determina si un documento es un Oficio (comunicación formal) o un Trámite (solicitud que requiere resolución administrativa), clasificándolo antes del proceso de catalogación detallada.

Indexación en motor de búsqueda

El contenido de cada documento, junto con sus metadatos extraídos, se indexa en Apache Solr para permitir búsquedas rápidas y eficientes.

Motor OCR intercambiable

La tecnología de reconocimiento de texto puede cambiarse entre distintos motores (OcrMyPDF, Tesseract) según las necesidades de la organización, sin modificar el resto del sistema.

Normalización de contenido (OCR)

Para documentos escaneados o imágenes, el sistema convierte automáticamente el contenido visual en texto legible por computadora, permitiendo su posterior análisis.

Pipeline de procesamiento en tres etapas

Cada documento sigue una secuencia obligatoria: (1) Normalización del contenido → (2) Extracción de metadatos → (3) Clasificación.

Reconocimiento de texto en español e inglés

El motor de reconocimiento óptico de caracteres procesa documentos en español e inglés simultáneamente, ideal para organizaciones con documentación bilingüe.

SEGUIMIENTO DE ESTADO Y TAREAS10 características

Animación de proceso en curso

Cuando un documento está siendo procesado activamente (normalizando, extrayendo o clasificando), aparece un indicador giratorio sobre el chip correspondiente, informando al usuario que hay trabajo en progreso.

Control de reintentos de tareas

Las tareas tienen un número máximo de reintentos configurables; si fallan repetidamente, se detienen y registran el error para revisión.

Cálculo de duración de tareas

Cada tarea registra su tiempo de inicio, permitiendo calcular cuánto tardó en completarse para análisis de rendimiento.

Estados de tarea en ciclo de vida completo

Las tareas de procesamiento pasan por estados claramente definidos: Pendiente → En Ejecución → Exitoso / Fallido, con registro de cada transición.

Indicadores visuales de estado del proceso

Cada documento en la lista muestra tres indicadores (N, E, C) que indican si ya fue Normalizado, Extraído y Clasificado respectivamente, con colores que distinguen los estados completados de los pendientes.

Limpieza automática de archivos temporales

Después del procesamiento OCR, los archivos temporales generados durante el análisis se eliminan automáticamente del servidor para liberar espacio.

Límite de tiempo por tarea

Aplica límites de tiempo a las tareas de normalización y extracción y cancela las que los superan.

Mensajes de progreso detallados por etapa

Durante el procesamiento, el sistema actualiza mensajes descriptivos en tiempo real sobre lo que está haciendo: obteniendo el archivo, ejecutando OCR, enviando al motor de búsqueda, etc.

Prevención de tareas duplicadas

El sistema verifica antes de iniciar cualquier tarea si ya existe una en curso para el mismo documento y tipo de operación, evitando procesar el mismo archivo dos veces simultáneamente.

Registro de tareas asíncronas

Cada operación de procesamiento se registra en la base de datos como una tarea con identificador único, tipo, estado, contador de acciones y mensajes de progreso.

VISUALIZACIÓN DE METADATOS11 características

Condición de visibilidad de detalles

El panel de detalles solo se habilita cuando el documento ya ha sido normalizado y tiene su contenido extraído, evitando mostrar información incompleta.

Panel de detalles del documento

Vista expandible dentro de la tabla que muestra todos los metadatos extraídos del documento: categoría, subcategoría, origen, destinatario, asunto, resumen, objetivo, identificador, términos legales, y más.

Vista de auditoría del documento

Muestra quién creó el registro en el sistema, quién lo modificó por última vez y las fechas correspondientes.

Vista de categoría y subcategoría

Muestra la clasificación principal (Oficio/Trámite) y la subcategoría específica asignada por la IA a cada documento.

Vista de destinatario

Muestra a quién fue dirigido el documento y su cargo u organización.

Vista de fecha de llegada

Muestra la fecha en que el documento fue recibido, tal como fue detectada por la IA en el contenido.

Vista de hechos y fundamentos

Muestra los argumentos y razones que sustentan la comunicación o solicitud del documento.

Vista de la solicitud específica

Presenta de forma clara la petición o pretensión concreta que contiene el documento.

Vista de origen y datos del remitente

Presenta quién envió el documento, a qué organización pertenece y su código o identificador de referencia.

Vista de resumen automático

Presenta un resumen generado por IA con los puntos más relevantes del contenido del documento.

Vista de términos legales identificados

Lista los términos jurídicos y administrativos detectados por la IA en el documento.

BÚSQUEDA E INDEXACIÓN7 características

Actualización inmediata del índice

Actualiza el índice cuando un documento se procesa o cambia su información.

Búsqueda con filtros combinados

Las búsquedas pueden combinarse con filtros por campos específicos (categoría, fecha, origen, etc.) para resultados más precisos.

Búsqueda por texto completo

Permite buscar documentos usando palabras o frases que aparezcan en cualquier parte del contenido del documento, no solo en el título.

Eliminación del índice al borrar documentos

Cuando un documento es eliminado del sistema, también se borra del motor de búsqueda para mantener consistencia entre ambos.

Motor de búsqueda empresarial Apache Solr

Indexa el contenido y los metadatos de documentos en Apache Solr para su consulta.

Paginación y ordenamiento en búsquedas

Los resultados de búsqueda pueden ordenarse por diferentes campos y navegarse en páginas para manejar grandes volúmenes de documentos.

Verificación de existencia en el índice

Antes de actualizar o eliminar registros en el motor de búsqueda, el sistema verifica que el documento exista en el índice, previniendo errores.

ARQUITECTURA Y PROCESAMIENTO ASÍNCRONO9 características

Arquitectura de microservicios

El sistema está dividido en componentes independientes: interfaz web, API, trabajadores de procesamiento, base de datos, motor de búsqueda, almacenamiento de archivos y servicio OCR, cada uno con su propio contenedor.

Cola de mensajes con Redis

Encola las tareas de procesamiento en Redis.

Conexión con reconexión automática al broker

Incluye reconexión automática al servicio de mensajería cuando se interrumpe la conexión.

Despliegue con contenedores Docker

Empaqueta los componentes en contenedores Docker para su despliegue y actualización.

Procesamiento en segundo plano

Las tareas pesadas como el reconocimiento de texto y la clasificación con IA se ejecutan en segundo plano (con Celery), sin bloquear la interfaz del usuario ni afectar el rendimiento del sistema.

Procesamiento paralelo de documentos

Permite configurar el procesamiento simultáneo de documentos mediante trabajadores asíncronos.

Red interna entre servicios

Los componentes del sistema se comunican entre sí a través de una red privada virtual (Docker network), sin exponer servicios internos al exterior.

Reinicio automático ante fallos

Configura el reinicio automático de los servicios ante fallos.

Separación entre servidor web y trabajadores

Separa el servidor web de los trabajadores de procesamiento de documentos.

SEGURIDAD Y AUTENTICACIÓN10 características

Autenticación mediante token JWT

El acceso al sistema se controla mediante tokens de seguridad (JWT) que verifican la identidad del usuario en cada operación, sin necesidad de enviar contraseñas repetidamente.

Cabeceras de autorización en todas las solicitudes

Cada petición del frontend al backend incluye automáticamente el token de seguridad en los encabezados HTTP.

Configuración CORS

Configura los orígenes autorizados para las solicitudes web mediante CORS.

Control de permisos por grupo

Los usuarios pertenecen a grupos con roles específicos que determinan qué acciones pueden realizar dentro del sistema.

Gestión de permisos desde Redux

Los permisos del usuario se cargan al iniciar sesión y se almacenan en el estado global de la aplicación, estando disponibles en toda la interfaz sin consultas repetidas al servidor.

Información de sesión en el token

Cada token de acceso contiene la identidad del usuario, su organización, correo electrónico, nombre de usuario e identificador de sesión, permitiendo una autorización precisa.

Integración con sistema de autenticación Creangel

El sistema se conecta a la plataforma de autenticación central de Creangel Technologies para verificar usuarios y obtener sus permisos y grupos.

Restricción de tipos de archivos permitidos

El sistema solo acepta formatos de archivo definidos en su configuración, rechazando cualquier archivo de tipo no permitido.

Validación de tamaño máximo de archivo

El sistema verifica que ningún archivo supere el límite de 50 MB antes de procesarlo.

Variables de entorno para credenciales

Gestiona las credenciales de los servicios mediante variables de entorno.

Página de información del proyecto

Página de inicio con descripción del sistema

Sistema de notificaciones en pantalla

Clasificación con salida estructurada

Solicita a la IA resultados estructurados en JSON para su procesamiento por el sistema.

Clasificación por función con invocación de herramientas

Utiliza invocación de herramientas para solicitar clasificaciones estructuradas.

Grafos de decisión con LangGraph

El flujo de clasificación se modela como un grafo de estados con LangGraph, permitiendo ramificaciones condicionales (Oficio vs.

Integración con OpenAI GPT-4o Mini

El sistema utiliza el modelo de lenguaje GPT-4o Mini de OpenAI para realizar la extracción de metadatos y la clasificación de documentos, aprovechando sus capacidades de comprensión del lenguaje natural.

Manejo de errores en respuestas de IA

Prompts especializados en lenguaje jurídico colombiano

Temperatura cero para consistencia en clasificación

Uso de LangChain para orquestación de IA

GESTIÓN DE DATOS Y BASE DE DATOS9 características

Base de datos relacional PostgreSQL

Toda la información del sistema (documentos, metadatos, tareas) se almacena en una base de datos PostgreSQL.

Eliminación en cascada de metadatos

Al eliminar un documento, sus metadatos asociados se eliminan automáticamente, manteniendo la integridad referencial de la base de datos.

Filtrado avanzado de listados

La API soporta filtros complejos en los listados de documentos, incluyendo búsqueda por texto en campos específicos, ordenamiento y paginación.

Metadatos de documento en tabla separada

La información extraída por IA (categoría, subcategoría, resumen, términos, etc.) se almacena en una tabla independiente vinculada al documento, manteniendo el modelo de datos organizado.

Migraciones de base de datos automatizadas

Los cambios en la estructura de la base de datos se gestionan mediante Alembic, permitiendo actualizar el esquema de forma controlada y versionada.

Modelo de documento con estados de procesamiento

Cada documento registra su estado en el pipeline: si requiere OCR, si su contenido fue normalizado, si está bajo normalización, si fue extraído, si está bajo extracción, si fue clasificado y si fue asignado.

Registro de auditoría por registro

Cada registro en la base de datos guarda quién lo creó, quién lo modificó por última vez, y las fechas de creación y edición.

Restricción de unicidad por nombre y organización

El sistema permite que no puedan existir dos documentos con el mismo nombre dentro de la misma organización, previniendo duplicados.

Soporte de arreglos de texto en base de datos

Los términos legales extraídos se almacenan como arreglos de texto en PostgreSQL, permitiendo múltiples valores en un solo campo.

API REST Y SERVICIOS WEB13 características

API REST versionada

Todos los servicios del sistema están disponibles a través de una API REST bajo la ruta /v1/, facilitando el mantenimiento y la compatibilidad con versiones futuras.

Endpoint de actualización de documentos (PUT)

Permite modificar el nombre de un documento existente.

Endpoint de clasificación de documento

Inicia el proceso de clasificación con IA para un documento específico, devolviendo un ticket de tarea.

Endpoint de consulta de documentos (GET)

Permite obtener la información detallada de un documento específico usando su identificador único.

Endpoint de consulta de metadatos

Permite obtener todos los metadatos extraídos de un documento (categoría, subcategoría, resumen, términos legales, etc.).

Endpoint de creación de documentos (POST)

Permite cargar uno o más archivos al sistema en una sola solicitud, creando los registros correspondientes en la base de datos.

Endpoint de descarga de archivo original

Permite descargar el archivo original del documento tal como fue cargado.

Endpoint de eliminación de documentos (DELETE)

Elimina un documento del sistema, incluyendo su archivo en el almacenamiento, su registro en el motor de búsqueda y todos sus metadatos.

Endpoint de extracción de contenido

Inicia el proceso de extracción de metadatos con IA para un documento específico, devolviendo un ticket de tarea.

Endpoint de listado con parámetros avanzados (POST)

Permite obtener listas de documentos con opciones de paginación, ordenamiento, filtrado y conteo total.

Endpoint de normalización de contenido

Inicia el proceso de OCR para un documento específico en segundo plano, devolviendo un ticket de tarea para seguimiento.

Respuestas estandarizadas de la API

Todas las respuestas de la API siguen un formato uniforme con campos de estado, mensaje y datos, facilitando su integración con otras aplicaciones.

Servicio Apache Tika para extracción de texto

Microservicio independiente basado en Apache Tika que recibe archivos PDF y devuelve su contenido textual; soporta PDF, DOC, DOCX y TXT.
